《金钱心理学》的6个要点

《金钱心理学：财富、人性和幸福的永恒真相》（The Psychology of Money，作者 Morgan Housel / 摩根·豪泽尔）是一本讲"钱和人性"的书——它谈的不是怎么选股票，而是怎么和金钱相处。下面是我的读书笔记，6 个要点。 先用一句话总述： 自由：财务自由 = 工作和生活选择的自由。 知足：知足才能避免失败。 复利之谜：投资最简单而有效的方法就是长期复利。 尾部的胜利：投资指数基金，留在牌桌上，长期复利。 合乎情理胜过绝对理性：目标 =（较好回报 + 较小风险 + 尽量小的遗憾）。 容错空间：为未来的变化和预测错误留出余地，不管世界发生什么疯狂的事，你都能活到明天。 1. 自由 查理·芒格：“我的目的并不是赚大钱。我想要的不过是独立自主而已。” 财务自由 = 工作和生活选择的自由。 “金钱最大的红利，就是让你拥有’在你想做的时候，和你喜欢的人在一起，做你想做的事，想做多久就做多久’的能力。” 2. 知足 “攀比就像一场没有人能打赢的战役，取胜的唯一办法是根本不要加入这场战争：用知足的态度接受一切，即使这意味着自己比周围的人逊色。” 麦肯锡公司的 CEO 因为贪婪从事内幕交易而被判入狱。 纳西姆·塔勒布：“退出无谓的激烈竞争，以获得内心平静为目标来调节你的行为，才是真正的成功。” 知足才能赢。 3. 复利之谜 巴菲特的净资产约为 845 亿美元：其中 815 亿是 65 岁以后赚到的，842 亿是 50 岁以后赚到的。 巴菲特的成功，一半归功于他是投资天才，另一半（更重要的一半）归功于他是个"长寿的老人"。他的技能是投资，但他的秘密是时间。 标普 500 指数在截至 2018 年的 50 年中上涨了 119 倍。你要做的只是坐下来安心等待，看着财富因复利不断增长。 在理财中，“活下去”（Survival）比"高回报"（High Returns）更重要。 查理·芒格：“复利的第一条原则是：除非万不得已，永远不要打断这个过程。” 投资最简单而有效的方法就是拉长时间。时间是投资中最强大的力量——它能让微不足道的事物成长壮大，而让重大错误的影响渐渐消失。 4. 尾部的胜利 统计学的"长尾效应"（Long Tail）：绝大多数回报，来自极少数的事件（分布曲线"尾部"的那些极端事件）。 失败是常态：大多数投资、决策、公司最终都会表现平平甚至失败。 成功靠极值：总体财富水平并不取决于那 90% 平庸的决定，而取决于那 1% 抓住了"超级大牛股"的决定——这 1% 的胜利会覆盖掉你所有其他的错误和损失。 沃伦·巴菲特：“自己一生中持有过 400～500 只股票，而收益的大部分来自其中的 10 只。” 查理·芒格：“如果去掉几笔顶级投资，公司的长期业绩其实相当普通。” 罗素 3000 指数中 40% 的公司最终以失败告终，但其中表现优异的 7% 足以抵消其余公司的失败。 2004–2014 年超过 2.1 万起创业融资中：65% 是亏损的；2.5% 获得 10～20 倍回报；1% 获得超过 20 倍回报；0.5%（约 100 家）获得超过 50 倍回报——这一小部分却是风险投资行业收入的主要来源。 投资指数基金，留在牌桌上，长期复利。 5. 合乎情理胜过绝对理性 投资的目标并不仅仅是最大收益，还应包括人性、心理和风险。可能的目标是：较好回报 + 较小风险 + 尽量小的遗憾。 诺贝尔经济学奖得主 Harry Markowitz（现代投资组合理论 Modern Portfolio Theory 的创始人）并没有用复杂的数学模型来管理自己的投资。他的投资结构是 50% 债券（Bonds）+ 50% 股票（Equities），为了最小化"遗憾"（Regret Minimization）： 股市大涨而他没买股票，他会觉得自己是傻瓜（遗憾）。 股市大跌而他全仓股票，他也会觉得自己是傻瓜（遗憾）。 为了晚上能睡好觉，他选择了简单粗暴的 50/50。 6. 容错空间 “价值投资之父"本杰明·格雷厄姆提到，投资时需要"安全边际”（Margin of Safety）。 比尔·盖茨在创立微软后：“想到了一个保守至极的办法，那就是要在银行里存足够多的钱。这样一来，即使公司没有了任何收益来源，我们也支付得起员工一年的工资。” 安全边际的目的在于让预测变得不再必要。 任何包含"死亡"（破产 / 归零）风险的赌局，无论赢面多大，都不能玩。 投资时为未来的变化和预测错误保留更多的容错空间（更多现金、更多储蓄、更少消费）：不管这世界发生什么疯狂的事，你都能活到明天。 六个要点，其实归到一句话：活得久、留余地，让时间和复利替你工作。 ...

Multi-Agent Deep Research: 原理和代码

之前写过一篇 Anthropic Deep Research: Multi-Agent 架构，讲 Anthropic 是怎么用 Multi-Agent 做 Deep Research 的。我按照那套架构用139 行 Python 实现了一个能并行搜索、带引用的 Deep Research。 原理：Orchestrator-Worker Anthropic 的核心思路是 Orchestrator-Worker（指挥者—工人）： Lead Agent（指挥者） —— 拆解问题，把一个大 query 切成几个互不重叠的子任务。 Subagents（工人） —— 每人领一个子任务，并行去搜索，各自有独立的 context window，完成任务后只把压缩过的 findings 返回给 Lead Agent。 Synthesis —— Lead Agent 把各路 findings 汇总成一篇连贯的报告。 Citation —— 最后统一给报告里的每个论断挂上来源链接。 为什么要多个 Agent？ 并行探索：多个 Subagent 同时进行，各自用独立的 context window，探索问题的不同侧面。 关注点分离（separation of concerns）：每个 Subagent 有自己独立的工具、prompt 和 Agentic Loop，这降低了路径依赖，让每条调查更深入、更独立。 突破单 context 上限：Deep Research 要处理的信息常常超出 Single-Agent 的 context window，多个 Agent 分摊是必要的。 Multi-Agent 有效，主要是因为它能 “花掉足够多的 token 来解决问题”。Anthropic 用 Claude Opus 4 为 Lead Agent、Claude Sonnet 4 为 Subagent 的系统，在内部研究评测上比 Single-Agent（用 Opus 4）效果高出 90.2%——代价是 token 消耗大得多，所以这套架构只适合高价值、可并行、超出单 context 的任务。 ...
